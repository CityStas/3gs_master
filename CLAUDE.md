# 3GS_Master

Правила проекта — `AGENTS.md` в корне репозитория. Он главнее этого файла; здесь только
переадресация, чтобы клиент, который не читает `AGENTS.md`, не остался без правил.

Два правила действуют всегда:

1. **Сначала RAG, потом код.** Вопрос про API движка → `threejs_rag_search` /
   `godot_rag_search` / `unity_rag_search` / `rbx_rag_search` **до** ответа, а не «когда
   совсем непонятно». База закреплена на версии (Three.js r186, Godot 4.7, Unity 6000.3);
   память модели — смесь версий, и ответ из неё почти всегда из другой.
2. **Ассеты — своей связкой.** `asset_image`, `asset_character`, `asset_to_3d`,
   `asset_remove_bg`, `asset_generate_pack` (MCP-сервер `assets`). Скачивание готового —
   второй эшелон; `ImageGen`, `VideoGen` и любые hosted API — не маршрут. Полная
   политика — `ASSET-POLICY.md`.

Если в списке инструментов нет `*_rag_search` — RAG-сервер не подключён. Скажи об этом,
а не отвечай по памяти. Проверить и развернуть: `gs mcp-sync --apply --client all`.
