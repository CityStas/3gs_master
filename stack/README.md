# stack/ - канонический стек проекта

Здесь лежит то, что копируется в **каждый** новый проект при
`newgame.cmd <имя>` или `dev.cmd <имя>`.

## Почему здесь, а не в чужой игре

Раньше стек искался в первой попавшейся игре (`find_sample`: любая папка с
`web3d/scene.js`). Создание проекта оказывалось заложником соседей: удалил одну
игру - перестали создаваться все остальные, а «образец» зависел от алфавитного
порядка имён. Теперь источник - сам репозиторий, и он один для всех.

## Что и откуда берётся

| В проекте | Откуда |
| --- | --- |
| `web3d/vendor/` | `vendor/three/` - рантайм three.js **r186** (ревизия та же, на которую написана документация в `knowledge/`; другая ревизия - врущая документация) |
| `web3d/scene.js` | `stack/web3d/scene.js` - этот каталог |
| `tools/level_apply.py` | `tools/level_apply.py` |
| `tools/level_edits.py` | `tools/level_edits.py` |
| `tools/level_lint.py` | `tools/level_lint.py` |
| `tools/web/serve.py` | `tools/web/serve.py` |

Таблица целиком - `STACK_SRC` в `tools/new_game.py`. Добавляешь файл в стек -
добавляешь строку туда, иначе он не попадёт в новые проекты.

## Чего здесь нет

**Оболочки студии.** `studio.html` и его модули лежат ОДНИ на все проекты -
в `<репозиторий>/studio`, и сервер отдаёт их по адресу `/web3d/studio.html`.
Копировать их в проект значит вернуть «сто игр - сто копий одного файла».

## Правило

Правишь `scene.js` - правишь **здесь**. Правка попадает во все новые проекты;
уже созданные обновляются через `newgame.cmd <имя> --sync`.
