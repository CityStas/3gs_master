# Лицензии внешних ассетов

Статус: знания. Это самый жёсткий раздел: нарушение лицензии — юридический риск
пользователя, а не техническая мелочь.

## Политика автоматического решения

```yaml
CC0:      auto_approve: true
CC-BY:    auto_approve: true, record_attribution: true
CC-BY-SA: auto_approve: false
GPL:      auto_approve: false
unknown:  auto_approve: false, reject: true
```

Читается так:

- **CC0** — можно брать сразу, без условий. Ни атрибуции, ни ограничений.
- **CC-BY** — можно брать сразу, но **обязательно записать автора и источник**.
  CC-BY без записанной атрибуции нарушает лицензию, даже если файл лежит в проекте.
- **CC-BY-SA** — автоматически нельзя. Share-Alike означает, что производное
  произведение наследует лицензию; для игры это не всегда приемлемо. Требовать
  решения пользователя.
- **GPL** — автоматически нельзя. GPL — лицензия кода, не ассетов; её попадание
  в проект требует отдельного разбора. Требовать решения пользователя.
- **unknown** — **отклонить**. Не «на всякий случай взять»: ассет с неопределённой
  лицензией это мина под коммерческий релиз.

## Что сообщать по каждому ассету

По любому ассету агент должен уметь ответить на четыре вопроса:

```
license                  — какая лицензия
commercial_use           — разрешено ли коммерческое использование
attribution_required     — требуется ли указание авторства
redistribution_allowed   — можно ли распространять сам ассет отдельно
automatic_install_allowed — можно ли ставить без отдельного разрешения
```

Последний пункт — не про лицензию, а про политику: даже у CC0-ассета установка в проект
меняет проект, поэтому решение об установке отдельно от решения о лицензии.

## Запись атрибуции (CC-BY)

Когда берётся CC-BY-ассет, в manifest пишется:

```
license: "CC-BY-4.0"
author: "<имя автора>"
source: "<название сайта>"
source_url: "<страница ассета>"
download_url: "<прямая ссылка на файл>"
attribution_required: true
```

Эти четыре поля (author, source_url, license, download_url) — ровно то, что нужно
для корректной строки атрибуции в игре: «Author, Source, License». Без любого из них
атрибуция неполная.

## Правила, которые нельзя нарушать

1. **Не расширять лицензию самостоятельно.** Если написано CC-BY-SA, нельзя решить,
   что «здесь это неважно». Решение принимает пользователь.
2. **Не брать ассет при неясной лицензии** — и не ставить его «пока, временно».
   Временное почти всегда становится постоянным.
3. **Не распространять целый пак.** Даже если лицензия позволяет, перепубликация
   чужого набора целиком — не задача агента. Берётся конкретный нужный ассет.
4. **Не подменять лицензию при переносе.** Копия ассета в проекте сохраняет исходную
   лицензию; файл `asset.json` рядом с ассетом — единственное место, где она зафиксирована.
5. **Не удалять `asset.json`.** Удаление манифеста теряет и лицензию, и атрибуцию —
   и проект молча становится нарушителем.

## Проверка после того, как ассет получен

Зафиксировать нельзя без проверки:

```
1. лицензия прочитана и записана;
2. author и source_url извлечены;
3. download_url сохранён (не только страница ассета);
4. sha256 посчитан от скачанного файла;
5. тип файла совпадает с ожидаемым.
```

Пункт 4 нужен не для красоты: см. `04_manifest.md` — по хешу ассет опознаётся
при повторном поиске и при проверке целостности.
