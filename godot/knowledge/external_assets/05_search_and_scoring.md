# Поиск, скоринг и форматы

Статус: знания.

## Что индексируется: только метаданные

Категорическое правило: в RAG по ассетам попадают **метаданные, а не файлы**.

Индексируемое:

```
name, description, tags, author, source, license,
format, Godot compatibility, asset type, style,
resolution, polycount, dependencies
```

Не индексируемое: сами `.png`, `.glb`, `.fbx`, `.wav`, `.zip`.

Причина: бинарники бессмысленны для текстового поиска и для эмбеддингов, но занимают
место и раздувают индекс. Искать нужно по описанию — «low-poly sci-fi container» —
а не по байтам модели.

## Гибридный поиск

По ассетам работает тот же принцип, что и по документации Godot: **dense + lexical**.

- **Dense (эмбеддинги)** — ловит смысл: запрос «контейнер для коридора» находит
  «cargo crate», даже если слов не совпало.
- **Lexical (BM25 / FTS)** — ловит точные совпадения: `glb`, `CC0`, `sci-fi`,
  `CharacterBody3D`, имя автора, имя пакета.

Оба нужны. Dense без lexical теряет точные технические термины, lexical без dense
теряет синонимы. Результаты сливаются ранговым слиянием — как в основном конвейере.

Reranker (bge-reranker) — опциональный третий слой. На текущей машине он не нужен:
выигрыш не оправдывает потерю VRAM, которую заберёт у основной модели.

## Скоринг кандидатов

Формула ранжирования:

```
final_score = relevance
            + license_score
            + godot_compatibility
            + format_score
            + quality
            + source_priority
            - size_penalty
            - import_risk
```

Веса, которые нужно применять:

```
лицензия CC0                      +30
ассет нативный для Godot          +25
формат GLB                        +15
высокая релевантность запросу     +30
большой архив                     -5
неизвестная лицензия              -100   <-- фактически отклонение
```

Обратите внимание на асимметрию: неизвестная лицензия весит как безусловный минус
в сто очков. Никакая релевантность не перекрывает лицензионный риск.

## Предпочтение форматов

### 3D

```
GLB / GLTF  ->  FBX  ->  OBJ
```

GLB/GLTF первым: это нативный для Godot формат с материалами и анимациями внутри
одного файла. FBX — рабочий, но с более частыми сюрпризами при импорте. OBJ —
последний: без материалов, без анимаций, только геометрия.

### Текстуры

```
PNG  ->  JPG  ->  WEBP  ->  EXR / HDR
```

PNG первым для обычных текстур (без потерь, с альфой). EXR/HDR — когда это
HDRI-окружение или карта высот: там нужен расширенный динамический диапазон,
и это не «худший» формат, а единственно верный для такой задачи.

### Звук

```
WAV  ->  OGG
```

WAV для коротких эффектов, OGG для музыки и длинных дорожек (меньше размер).
MP3 избегать: лицензионные ограничения и не лучшая поддержка.

## Что считать «качеством»

```
quality — это не только «красиво»:
  - есть ли превью/описание у ассета;
  - указан ли автор;
  - указан ли полигонаж;
  - единый ли стиль внутри пака;
  - есть ли у ассета внятная страница.
```

## Чего агент не должен делать при выборе

- Выбирать по размеру в ущерб формату: «маленький OBJ» хуже «чуть большего GLB».
- Игнорировать `godot_compatibility`: ассет под Godot 3 в 4.7 может не открыться.
- Брать первый результат без сравнения минимум двух-трёх кандидатов, когда их несколько.
- Ранжировать по «нравится» вместо формулы выше.
