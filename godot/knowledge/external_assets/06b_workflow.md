# Workflow: от запроса пользователя до работающего ассета в сцене

Статус: знания. Это пошаговый порядок действий. Применяется, когда инструменты есть.
Сегодня их нет — поэтому раздел используется как **план**, который агент излагает
пользователю, и как **критерий проверки**, если ассет принёс сам пользователь.

## Полная цепочка

```
1.  классифицировать запрос          — нужен ли внешний ассет вообще
2.  определить потребность           — что именно нужно: тип, стиль, формат
3.  поиск в локальном индексе        — нет ли уже в проекте / в манифесте
4.  переиспользовать или искать      — решение о дедупликации
5.  поиск по источникам              — по ветке A/B/C/D (см. 02_*)
6.  получить кандидатов              — 2-3 варианта, не один
7.  inspect каждого кандидата        — формат, размер, совместимость
8.  проверить лицензию               — по таблице auto_approve
9.  ранжировать                      — по формуле скоринга
10. выбрать                          — с обоснованием выбора
11. скачать                          — во временную папку
12. валидировать                     — тип файла + sha256
13. записать asset.json              — provenance
14. установить                       — в res://assets/external/<pack>/
15. импортировать в Godot            — переимпорт ресурсов
16. осмотреть в Godot                — ассет открывается
17. собрать и запустить сцену        — проверить, что реально работает
18. починить, если что-то не так     — итерация
19. отчитаться                       — что принесено, откуда, под какой лицензией
```

Шаги 3–4 идут **до** внешнего поиска. Это принципиально: искать в интернете то, что
уже лежит в проекте, — трата времени и путь к разъехавшимся копиям.

## Шаг 1 подробнее: нужен ли внешний ассет

Не каждый запрос требует ассета. Порядок решений:

```
нужен код/логика?         -> писать код, ассет не нужен
нужен примитив?           -> MeshInstance3D / ColorRect / Polygon2D хватит
нужен визуал, которого
  нет в проекте?          -> внешний ассет уместен
```

Например, «сделай красный куб, который летает» — это `MeshInstance3D` + скрипт, а не
скачивание модели. Внешний ассет нужен, когда запрос именно про конкретную внешность:
«поставь sci-fi контейнеры», «нужен тайлсет травы».

## Шаг 6–10 подробнее: выбор кандидата

Правило: **не выбирать первый результат**. Минимум два-три кандидата, сравнение
по лицензии, формату и совместимости, затем формула скоринга.

Обоснование выбора должно быть воспроизводимым. Плохо: «взял этот, выглядит норм».
Хорошо: «этот: CC0 (+30), GLB (+15), Godot 4.x (+25), совпадение по тегам; альтернатива
из itch.io имела CC-BY-SA, требует одобрения».

## План ассетов для составного запроса

Когда запрос описывает сцену целиком («собери маленький sci-fi коридор»), сначала
определяется **список необходимых ассетов**, и только потом ищется каждый.

```
asset_plan("маленький sci-fi коридор")
-> needed_assets:
     - floor tiles (modular, 2x2)
     - wall segments (modular)
     - ceiling pieces
     - door frame
     - cargo crate / container (prop)
     - pipe or vent (prop)
     - hanging light (prop)
```

Польза: видно объём работы до начала, видно, какие пункты можно закрыть одним паком
(модульные коридоры часто одним), и видно, что часть пунктов решается примитивами.
Без плана агент приносит первый ассет, ставит его и останавливается.

## Пример: sci-fi контейнер

Показательный разбор, как должен выглядеть правильный ход мысли.

```
запрос:  «нужен бесплатный low-poly sci-fi контейнер»

1. категория: 3D-модель, проп -> ветка B
2. источник: Poly Haven первый, но там реалистичные модели;
             запрос про low-poly -> Quaternius / Kenney
3. кандидаты: Quaternius (CC0, GLB), Kenney (CC0, GLB)
4. лицензия: CC0 у обоих -> auto_approve
5. формат: GLB у обоих -> +15
6. выбор: Kenney — ближе по стилю к остальным ассетам проекта
7. результат пользователю:
     - что взято: sci-fi container
     - откуда: Kenney, <ссылка на страницу>
     - лицензия: CC0, атрибуция не требуется
     - куда установлено: res://assets/external/kenney_scifi/container.glb
     - манифест: res://assets/external/kenney_scifi/asset.json
```

## Что считается завершением

Задача не закончена на «файл скачан». Готовность — это:

```
[ ] ассет в res://assets/external/<pack>/
[ ] asset.json рядом, все обязательные поля заполнены
[ ] sha256 посчитан
[ ] ассет импортирован Godot (открывается)
[ ] сцена с ассетом запускается без ошибок
[ ] лицензия проверена и позволяет использование
[ ] атрибуция записана (для CC-BY)
[ ] пользователю сообщено: что, откуда, под какой лицензией
```

«Скачал» — это шаг 11 из 19, а не результат.
