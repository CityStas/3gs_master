# Источники внешних ассетов

Статус: знания. Скачать по этим ссылкам агент **не может** — сетевого инструмента нет.
Ссылки даются, чтобы агент назвал пользователю точный источник и не выдумывал URL.

## Godot Asset Store — приоритет 1 для всего Godot-специфичного

Самый первый источник, когда нужен аддон, плагин, инструмент, шейдер или шаблон проекта,
а не художественный ассет.

- Новый магазин: `https://store.godotengine.org/search/`
- Старая библиотека (fallback): `https://godotengine.org/asset-library/asset`

Почему первый: ассеты там уже сделаны под Godot, версия движка указана, импорт обычно
без сюрпризов. Для «нужен инвентарь / диалоговая система / тайлмап-редактор» идти сюда,
а не за спрайтами.

Не путать: Asset Store — это **код и инструменты**, Kenney и itch.io — **арт**.

## Poly Haven — приоритет 2 для 3D, PBR, HDRI

- Сайт: `https://polyhaven.com/`
- API (официальный, есть документация): `https://polyhaven.com/id/our-api`

Всё CC0. Модели, PBR-текстуры, HDRI-окружения. Для окружения 3D-сцены — лучший
источник: HDRI даёт освещение сразу, без настройки источников света вручную.

**Важно: у Poly Haven есть API — НЕ нужно делать web scraping.** Официальный API
предпочтительнее парсинга страниц всегда: он стабилен, не нарушает условия и не ломается
от редизайна сайта. Если инструмент скачивания появится, для Poly Haven он должен ходить
через API.

## Kenney — приоритет 3 для 2D и прототипов

- Каталог: `https://kenney.nl/assets`
- Отдельные наборы:
  - `https://kenney.nl/assets/prototype-kit`
  - `https://kenney.nl/assets/new-platformer-pack`
  - `https://kenney.nl/assets/development-essentials`
  - `https://kenney.nl/assets/game-icons`

Лицензия CC0. Стиль — аккуратный плоский минимализм, единый по всем наборам, что важно:
наборы между собой сочетаются. Идеально для прототипа и для 2D-платформера.

Отдельная ценность — `game-icons`: иконки для UI и предметов, тоже CC0.

## Quaternius — приоритет 4 для low-poly 3D

- Сайт: `https://quaternius.com/`

Низкополигональные 3D-модели: персонажи, монстры, окружение, транспорт. Лицензия
разрешительная (проверять на конкретном паке). Хороший выбор, когда нужен 3D-контент
с малым полигонажем и без реалистичных текстур.

## itch.io — приоритет 5, глубокий каталог 2D

- Все бесплатные Godot-ассеты: `https://itch.io/game-assets/free/tag-godot`
- Только CC0: `https://itch.io/game-assets/assets-cc0/free/tag-godot`
- Royalty-free: `https://itch.io/game-assets/free/tag-godot/tag-royalty-free`
- Прототипы: `https://itch.io/game-assets/free/prototypes/tag-godot`
- Платформеры: `https://itch.io/game-assets/free/genre-platformer/tag-godot`

Самый большой каталог, но и самый неоднородный по лицензиям. Здесь **обязательно**
проверять лицензию на странице конкретного ассета: под тегом free лежит всё, включая
CC-BY-SA и лицензии с ограничением на коммерческое использование.

Порядок ссылок в списке — от самой безопасной выборки к самой широкой: если нужен
безопасный путь, идти по cc0-ссылке.

## OpenGameArt — приоритет 6

- Сайт: `https://opengameart.org/`

Старый крупный архив. Много классического пиксель-арта и тайлсетов. Лицензии смешанные —
фильтровать по лицензии перед выбором, страница ассета всегда указывает лицензию отдельно.

## GameDev Market — приоритет 7

- Сайт: `https://www.gamedevmarket.net/`

В основном платный. Использовать, когда бесплатных аналогов нет; бесплатных ассетов
меньше, и условия у них часто строже.

## Чего агент делать не должен

- Придумывать URL. Если ссылки нет в этом файле или в результатах поиска — не выдумывать
  «похожий» адрес: угаданная ссылка ведёт на чужой или мёртвый ресурс.
- Обходить CAPTCHA, форму логина, DRM, платный доступ, ограничения по частоте запросов
  и закрытые/приватные эндпоинты. Если источник требует входа — ассет не берётся.
- Скрапить Poly Haven, когда есть API.
- Скачивать платный ассет, найдя его «бесплатную копию» на стороннем сайте.
