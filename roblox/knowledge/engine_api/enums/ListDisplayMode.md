# ListDisplayMode

Used to set the scrolling mode of the Advanced Objects tab.

**Type:** enum

## Items

| Name | Value | Description |
|------|-------|-------------|
| `Horizontal` | 0 | Scrolling along the X-axis (fixed Y-Axis). |
| `Vertical` | 1 | Scrolling along the Y-axis (fixed X-Axis). |
