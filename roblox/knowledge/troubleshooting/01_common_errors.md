# Troubleshooting: частые ошибки Roblox и что они значат

## «attempt to index nil with 'X'»

Самая частая ошибка. `X` ищется у объекта, которого нет.

| Причина | Проверка |
|---|---|
| `FindFirstChild` вернул `nil`, а результат используют без проверки | `if not obj then return end` |
| имя члена написано в нижнем регистре (`:findFirstChild`) | `rbx_lint` ловит правило `method-case` |
| объект ещё не отреплицирован на клиент | `:WaitForChild("X", 5)` вместо `.X` |
| `player.Character` равен `nil` (персонаж ещё не загружен) | `player.CharacterAdded:Wait()` |
| `LocalScript` требует модуль из `ServerStorage` | модуль недоступен клиенту; перенести в `ReplicatedStorage` |

## «Infinite yield possible on 'ReplicatedStorage:WaitForChild("X")'»

`X` не появился за 5 секунд (Studio пишет это предупреждение именно после таймаута).
Значит, объект либо не создан на сервере, либо создан с другим именем, либо создан
*после* того, как клиент начал ждать, и не реплицирован. Проверить: `search_game_tree`
в Studio MCP, затем `rbx_search_scripts "X"`.

## Скрипт «не работает», ошибок нет

1. `Disabled = true`.
2. `LocalScript` лежит в `ServerScriptService` (никогда не запустится).
3. `Script` лежит в `StarterGui` (никогда не запустится).
4. Это `ModuleScript` — он не запускается сам, его надо `require`.
5. Синтаксическая ошибка выше по файлу: скрипт не скомпилировался целиком, но снаружи это
   выглядит как «ничего не происходит». `rbx_lint` ловит несбалансированный `end`.

## RemoteEvent не срабатывает

| Симптом | Причина |
|---|---|
| «Remote event invocation discarded» | событие отправлено до репликации remote-объекта; создавать remote на сервере и ждать на клиенте через `WaitForChild` |
| обработчик на сервере не вызывается | `OnServerEvent` подключён через `.` вместо `:` |
| обработчик вызывается, но аргументы не те | первый аргумент `OnServerEvent` — всегда `Player`, его добавляет движок |
| работает в Play, не работает в Start Server + Player | в одном окне клиент и сервер делят DataModel, репликация не проверяется |

## «DataStore request was added to queue»

Превышен бюджет. Вызов не упал, он в очереди; при переполнении — **отбрасывается молча**.
Лечение: реже, крупнее, кэшем. Не `GetAsync` на каждое действие игрока.

## «Cannot store dictionary in data store»

В данных есть несериализуемое: `Instance`, функция, `Vector3` в перемешанной таблице,
таблица с дырой (`nil` в середине массива). Проверить структуру перед `SetAsync`.

## Сцена пустая / объекты не видны

- `CanCollide`/`Transparency` не при чём: объект может быть за `Camera` или под полом.
- `StreamingEnabled`: клиент не получает дальние части мира. `WaitForChild` для них
  зависает — это ожидаемо, а не баг.
- Объект создан на клиенте (`Instance.new` в `LocalScript`) — его не увидят другие.

## Лаги и просадка FPS

| Причина | Что делать |
|---|---|
| `while true do ... end` без `task.wait` | добавить `task.wait()`; `rbx_lint` ловит правило `busy-loop` |
| `Instance.new` в цикле каждый кадр | создавать заранее и переиспользовать |
| тысячи отдельных `Part` вместо `UnionOperation`/мешей | объединять, включать `StreamingEnabled` |
| `GetChildren()` каждый кадр | кэшировать, обновлять по событиям |
| `Humanoid` на каждом NPC с полным `Animator` | упрощать для дальних NPC |

## Ошибки в Studio MCP

| Симптом | Причина |
|---|---|
| список студий пуст | Studio закрыта или выключен «Enable Studio as MCP server» |
| инструменты висят | в Studio открыт модальный диалог |
| правки исчезают | правка сделана в Play-режиме и отброшена при остановке |
| `execute_luau` ничего не делает | не тот контекст: серверный вызов в Client-контексте |
